# ServiceNow – Import Data using Transform Maps

## Project Title
**Import Data using Transform Maps (Spreadsheet)**

## Description
This project demonstrates how spreadsheet data can be imported into ServiceNow using Import Sets and Transform Maps.

## Technologies Used
- ServiceNow
- Import Sets
- Transform Maps
- Spreadsheet / Excel
- ServiceNow Tables

## Project Workflow

Spreadsheet Data  
↓  
Import Set  
↓  
Import Set Table  
↓  
Transform Map  
↓  
Target Table  
↓  
Imported Records

## Key Features
- Import data from a spreadsheet
- Create and configure a target table
- Create an Import Set
- Configure a Transform Map
- Map source fields to target fields
- Transform and load data into the target table
- Verify imported records
